CSS Box Model

CSS Box Model არის CSS-ის მნიშვნელოვანი კონცეფცია, რომელიც გვიჩვენებს, როგორ არის HTML ელემენტი აგებული და რამდენ ადგილს იკავებს ვებგვერდზე.

Content → Padding → Border → Margin

რა არის Box Model?

ყველა HTML ელემენტი შეიძლება წარმოვიდგინოთ როგორც ყუთი.

Content

Box Model შედგება ოთხი ძირითადი ნაწილისგან:

  • Content
  • Padding
  • Border
  • Margin

Content

Content არის ელემენტის მთავარი შიგთავსი.

Content-ში შეიძლება იყოს ტექსტი, სურათი, ღილაკი ან სხვა HTML ელემენტი.

width: 300px;
height: 100px;

Padding

Padding არის სივრცე Content-სა და Border-ს შორის.

Padding ქმნის შიდა დაშორებას.

padding: 20px;

რაც უფრო დიდია Padding, მით უფრო მეტი სივრცეა Content-ის გარშემო, ელემენტის შიგნით.

Border

Border არის ელემენტის საზღვარი.

border: 5px solid black;
  • 5px — საზღვრის სისქე
  • solid — საზღვრის ტიპი
  • black — საზღვრის ფერი

Margin

Margin არის სივრცე ელემენტის გარეთ.

ის ქმნის დაშორებას ელემენტსა და სხვა ელემენტებს შორის.

margin: 20px;

მარტივად:

Padding = შიგნით
Margin = გარეთ

Content-box

content-box არის Box Model-ის ნაგულისხმევი მნიშვნელობა.

ამ შემთხვევაში width და height ეხება მხოლოდ Content-ს.

box-sizing: content-box;
width: 300px;
padding: 20px;
border: 5px solid black;

საბოლოო სიგანე:

300 + 40 + 10 = 350px

Border-box

border-box-ის დროს width და height უკვე მოიცავს Content-ს, Padding-ს და Border-ს.

box-sizing: border-box;
width: 300px;
padding: 20px;
border: 5px solid black;

საბოლოო სიგანე:

300px

Content-box vs Border-box

Content-box

Width მოიცავს მხოლოდ Content-ს.

Padding და Border ემატება საბოლოო ზომას.

Border-box

Width მოიცავს Content-ს, Padding-ს და Border-ს.

საბოლოო ზომა რჩება მითითებული Width-ის ფარგლებში.

საბოლოო ზომის მაგალითი

გვაქვს:

width: 300px;
padding: 20px;
border: 5px solid black;

Content-box

300 + 40 + 10

350px

Border-box

Padding და Border შედის 300px-ში

300px

დასკვნა

CSS Box Model-ის ოთხი ძირითადი ნაწილია:

Content → Padding → Border → Margin

Content არის შიგთავსი.
Padding არის შიდა დაშორება.
Border არის საზღვარი.
Margin არის გარე დაშორება.

content-box-ში Padding და Border ემატება ზომას, ხოლო border-box-ში ისინი უკვე შედის მითითებულ ზომაში.
