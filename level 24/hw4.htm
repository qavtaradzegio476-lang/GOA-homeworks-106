CSS Box Model

CSS Box Model არის მოდელი, რომლის მიხედვითაც HTML ელემენტები ყალიბდება როგორც ყუთები.

Box Model შედგება ოთხი ძირითადი ნაწილისგან:

  • Content
  • Padding
  • Border
  • Margin

1. Content

Content არის ელემენტის მთავარი შიგთავსი.

მაგალითად, ტექსტი, სურათი ან სხვა HTML ელემენტი შეიძლება იყოს Content.

ეს არის Content

2. Padding

Padding არის შიდა დაშორება Content-სა და Border-ს შორის.

Padding ელემენტის შიგნით ტოვებს დამატებით სივრცეს.

Content

↑
Padding არის ეს სივრცე

3. Border

Border არის ელემენტის ჩარჩო.

Border-ს შეგვიძლია მივუთითოთ სისქე, ფერი და სტილი.

ეს არის Border-ის მაგალითი

მაგალითი: border: 5px solid black;

4. Margin

Margin არის გარე დაშორება.

ის ელემენტს სხვა ელემენტებისგან აშორებს.

პირველი ელემენტი
მეორე ელემენტი

ამ ორ ელემენტს შორის დაშორება შექმნა Margin-მა.

Box Model-ის სტრუქტურა

Box Model-ის ნაწილები ცენტრიდან გარეთ ასე გამოიყურება:

Content → Padding → Border → Margin

Content არის ცენტრში, შემდეგ მოდის Padding, შემდეგ Border და ბოლოს Margin.

content-box

content-box არის box-sizing-ის ნაგულისხმევი მნიშვნელობა.

როდესაც ვიყენებთ content-box-ს, width და height მხოლოდ Content-ის ზომას განსაზღვრავს.

width: 200px;
padding: 20px;
border: 5px;

საბოლოო სიგანე: 200 + 20 + 20 + 5 + 5 = 250px

border-box

border-box-ის დროს width და height უკვე მოიცავს Content-ს, Padding-ს და Border-ს.

width: 200px;
padding: 20px;
border: 5px;
box-sizing: border-box;

საბოლოო სიგანე მაინც 200px იქნება.

content-box VS border-box

content-box: width მოიცავს მხოლოდ Content-ს.

Padding და Border შემდეგ ემატება.

border-box: width მოიცავს Content-ს, Padding-ს და Border-ს.

ამიტომ border-box-ის გამოყენებისას ელემენტის საბოლოო ზომის კონტროლი უფრო მარტივია.

დასკვნა

CSS Box Model ძალიან მნიშვნელოვანია ვებგვერდის დიზაინისა და ელემენტების განლაგებისთვის.

  • Content — ელემენტის შიგთავსი
  • Padding — შიდა დაშორება
  • Border — ელემენტის ჩარჩო
  • Margin — გარე დაშორება

ასევე მნიშვნელოვანია განსხვავება content-box-სა და border-box-ს შორის.

მადლობა ყურადღებისთვის!
